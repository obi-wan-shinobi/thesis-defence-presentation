\begin{frame}
	\note<1->{
		A neural network is just a rule that turns an input into an output,
		which is what we mean by a function. We are given example input output
		pairs and we want a function that agrees with them and, more
		importantly, gives sensible answers for inputs we have not seen, which
		is what generalize means. The way we get there is to adjust the
		function until its outputs on the examples are close to the true
		outputs, and the squared error written here just measures how far off
		it is. But we cannot try arbitrary functions one by one, so instead we
		fix a family of functions described by a set of adjustable numbers, the
		parameters, and learning means tuning those numbers. Keep the word
		unknowns in mind: the next motivation slide counts parameters against
		data points exactly like unknowns against equations. The next slide
		looks at what such a function is actually built from.
	}
	\vspace{0.5em}
	\slidetitle{INTRODUCTION}{Supervised Learning: Fitting data to a function}

	\vfill
	\begin{columns}[c,onlytextwidth]
		\begin{column}{0.52\textwidth}
			\setlength{\parskip}{2.2mm}\small

			\visible<2->{{\color{blue}\bfseries Data:}\ \ $n$ observations $(x_i, \targetf(x_i))$, examples of an unknown target function $\targetf$.\par}

			\visible<3->{{\color{green}\bfseries Model:}\ \ a learned prediction function $\modelf(x)$.\par}

			\visible<4->{{\color{blue}\bfseries Aim:}\ \ predict the target output $\targetf(x)$ for a new, unseen input $x$.\par}

			\visible<5->{{\color{orange}\bfseries How:}\ \ choose $\modelf$ so its predictions are close to the target function on the observed data, i.e.\ minimise
				$\mathcal{L}(f) = \displaystyle\frac{1}{n}\sum_{i=1}^{n}\big(\underbrace{\modelf(x_i)-\targetf(x_i)}_{:=\,r_i}\big)^2$.\par}

			\visible<6->{{\color{green}\bfseries In practice:}\ \ we cannot
				search over all possible functions, so we fix a parameterized
				family ${\color{tudcyan}f_\theta}(x)$ and learn by adjusting the
				parameters $\theta$. The parameters are the unknowns the data must
				pin down.\par}
		\end{column}
		\begin{column}{0.40\textwidth}
			\centering
			\input{fit_intuition.tex}
		\end{column}
	\end{columns}

\begin{frame}
	\note<1->{
		Spectral bias is the tendency of neural networks trained with gradient descent to learn low-frequency structure before high-frequency detail.

		In other words, the network first captures the smooth, global shape of the target, and only later fits the more oscillatory parts.

		That is what these examples are meant to show. Even though the architectures are different, the learning process has the same qualitative pattern: low-frequency modes appear early, high-frequency modes are delayed.

		My thesis asks whether we can explain this from the training dynamics.

		The main idea is to reformulate spectral bias as an operator eigenvalue problem. If an operator governs the residual dynamics, then its eigenvalues determine which frequencies are learned quickly and which ones are learned slowly.

		So the three guiding questions are: what controls mode-wise learning rates, does the explanation survive finite data, and does it survive finite width?
	}
	\vspace{0.5em}
	\slidetitle{THESIS}{Why does gradient descent learn simple structure first?}
	{\small\textcolor{muted}{This pattern has a name: the frequency principle, also called spectral bias (\href{https://arxiv.org/abs/1901.06523}{Xu et al., 2019}).}}

	\vspace{1.8mm}

\begin{frame}
	\note<1->{
		Picture the error as a landscape: high where the network is wrong, low
		where it fits. Training rolls downhill, taking the steepest way down, which
		is why it is called gradient descent. Notice the steps shrink as it nears
		the bottom: the closer the error gets to zero, the smaller the correction,
		because the slope itself is proportional to how much error is left. Then we
		look at the same bowl from straight above. The rings are contours, lines of
		equal height, so closely spaced rings mean steep and widely spaced rings
		mean shallow. This bowl has a steep direction and a shallow one, and that is
		the distinction the next slide builds on.
	}
	\vspace{0.5em}
	\slidetitle{BACKGROUND}{The error is a landscape}
	{\textcolor{muted}{Seen from above, the contour rings are the bowl's height; training rolls toward the bottom.}}

	{\raggedleft\tiny\textcolor{muted}{recall the loss: $\mathcal{L}(f) = \tfrac1n\sum_i\big(f(x_i)-f^\star(x_i)\big)^2$}\par}

	\vspace{2mm}

% Keystone slide: "rate = eigenvalue", introduced geometrically before any
% NTK machinery. Self-contained TikZ (no external assets). The Latex arrow
% tips need the arrows.meta library, which the preamble does not load, so we
% load it locally here to keep this frame self-contained.
\usetikzlibrary{arrows.meta}
\begin{frame}
	\note<1->{
		One sentence on what training does: it makes the error small. It does this by
		walking downhill on the error, stepping in the direction the error drops
		fastest, which is the negative gradient, hence gradient descent. Now the
		question this slide answers: why do different directions get learned at
		different speeds. Picture the error landscape as a stretched bowl. In the
		bowl's own tilted coordinates the descent path mixes the two directions
		together, so you cannot read off a clean rate for either one. The fix is to
		use the bowl's own axes as coordinates. These special directions, the
		eigenvectors, are the ones the dynamics never mixes. Along a single one of
		them the error falls in proportion to how much is left, the differential
		equation here, which is the same law as a cooling cup of coffee or
		radioactive half-life, so it decays exponentially, alpha of t equals alpha of
		zero times e to the minus lambda t. The rate lambda is the eigenvalue, large
		is fast, small is slow. Everything after this works out what these directions
		and rates are for a real network on the circle.
	}
	\vspace{0.4em}
	\slidetitle{BACKGROUND}{Each direction has its own rate}
	{\textcolor{muted}{Training makes the error small by walking downhill, along the steepest drop.}}\par
	{\raggedleft\tiny\textcolor{muted}{recall the loss: $\mathcal{L}(f) = \tfrac1n\sum_i\big(f(x_i)-f^\star(x_i)\big)^2$}\par}

	\vspace{1mm}
	% ---------- ROW 1: the bowl, coupled then rotated to its own axes ----------
	\begin{columns}[c,onlytextwidth]
		\begin{column}{0.45\textwidth}
			\centering
			\visible<1->{

					\draw[line] (0,-1.7)--(0,1.7);
					\node[muted,font=\tiny] at (2.66,0.0) {$x$};
					\node[muted,font=\tiny] at (0.0,1.9) {$y$};
					% Tilted contour ellipses: principal axes at 30 deg, NOT along x, y.
					\foreach \r in {1.0,0.861,0.707,0.544,0.36}{
							\draw[tudcyan,opacity=0.55,rotate=30] (0,0) ellipse ({1.95*\r} and {1.36*\r});
						}
					% Curved gradient-descent path in x, y: each step crosses the
					% tilted contours, so the route bends (the coordinates are
					% coupled). Matches the lead-in path; starts high off the x axis,
					% the steep part dies first, then it slides along the shallow axis.
					\draw[orange,very thick]

						}

				\end{tikzpicture}\par\vspace{0.5mm}
				{\scriptsize\textcolor{muted}{In x, y axes the two directions are coupled.}}
			}
		\end{column}

\begin{frame}
	\note<1->{
		Picking up the question from the last slide. For a single direction the error
		obeyed alpha dot equals minus lambda alpha, the rate was one number. For a
		network the error is a whole function, the residual, and it still falls in
		proportion to how much is left, but the proportion is no longer a number. It
		is an operator acting on the whole function, and that operator is the neural
		tangent kernel. The residual obeys r dot equals minus T r. This holds for any
		differentiable model under gradient flow, which is why I am not writing the
		network down yet. If T were a fixed operator, diagonalizing it would split
		this back into one copy of the scalar law per eigenfunction, alpha k dot
		equals minus lambda k alpha k. So the eigenfunctions are the directions and
		the eigenvalues are the rates, and the question from the last slide becomes:
		what is the spectrum of T.
	}

	{\textcolor{muted}{The same law as before, with the single rate replaced by an operator.}}

% Main results, message-first: on a fixed low-frequency Fourier window both
% finite-scale errors shrink like 1/sqrt(scale). The precise matrix
% statements (A, G, H, B_m^{(K)}, norms, constants) moved to the backup
% frame "Finite-scale bounds: precise statements".
\begin{frame}
	\note<1->{
		\begin{itemize}
			\item Fix the window: Fourier modes up to frequency $K$, $d=2K+1$ of them.
			\item Finite data: sampled Fourier geometry $\approx$ ideal; error $O(n^{-1/2})$.
			\item Frozen width: operator correct on average; error $O(m^{-1/2})$.
			\item Both high probability, explicit constants; precise statements in backup.
		\end{itemize}
	}
	\slidetitle{NON-ASYMPTOTIC CONTROL}{Main results: the spectral picture survives finite scale}
	{\textcolor{muted}{Fix a low-frequency window: the Fourier modes up to frequency $K$, $d=2K+1$ of them. Compare each finite-scale object to its ideal counterpart there.}}

	\vspace{2mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.49\textwidth}
			\begin{yellowcard}[height=36mm]
				{\textcolor{orange}{\bfseries Finite samples}\hfill{\tiny\textcolor{muted}{Thm.~5.5}}}\par\vspace{1.5mm}
				{\scriptsize Train on $n$ sampled points instead of the whole circle. On the window, the sampled Fourier geometry (orthogonality, eigenvalues, kernel action) deviates from the ideal one by at most}\par\vspace{-1.5mm}
				\[
					C\,\sqrt{\frac{\log(nd/\delta)}{n}}
				\]
				\vspace{-4mm}\par
				{\tiny\textcolor{muted}{with probability $1-\delta$, for explicit constants $C$.}}
			\end{yellowcard}
		\end{column}
		\pause
		\begin{column}{0.49\textwidth}
			\begin{purplecard}[height=36mm]
				{\textcolor{purple}{\bfseries Frozen finite width}\hfill{\tiny\textcolor{muted}{Thm.~5.6}}}\par\vspace{1.5mm}
				{\scriptsize Replace the ideal operator by a width-$m$ network's tangent operator at initialization. On the window it equals the ideal one \emph{on average}, and deviates by at most}\par\vspace{-1.5mm}
				\[
					C\,\sqrt{\frac{\log(d/\delta)}{m}}
				\]
				\vspace{-4mm}\par
				{\tiny\textcolor{muted}{with probability $1-\delta$; on average: $\mathbb{E}[\text{finite-width block}]=\text{ideal block}$.}}
			\end{purplecard}

	\pause
	\begin{whitecard}
		\centering
		{\scriptsize\bfseries Takeaway:}\ {\scriptsize finite-sample errors shrink like $O(n^{-1/2})$, frozen finite-width errors like $O(m^{-1/2})$, both on the same fixed low-frequency subspace: the spectral picture degrades gracefully.}
	\end{whitecard}

	\vspace{1mm}
	{\tiny\textcolor{muted}{Rates up to log factors; precise statements and constants in backup.\quad Finite scale vs.\ idealized kernel dynamics: Bowman \& Mont\'ufar (2022).}}
\end{frame}

\begin{frame}
	\note<1->{
		\begin{itemize}
			\item So far, the story has been: start from the ideal operator, then control finite-sample and frozen finite-width errors.
			\item But this still leaves out normal training.
			\item In normal training, the tangent kernel is allowed to move:
			      \[
				      T_0^{(m)} \rightsquigarrow T_t^{(m)}.
			      \]
			\item The question is whether that movement actually matters.
			\item At $m=128$ and $m=256$, it clearly does: the evolving kernel reaches much lower loss than the frozen one.
			\item At $m=1024$, the reversal appears: the frozen kernel reaches the lower final loss.
			\item So kernel evolution seems to be a genuine small-width effect.
			\item This is the main tension: finite width can improve learning by changing the operator, but it also breaks the clean spectral reference model.
		\end{itemize}
	}
	\slidetitle{EVOLVING KERNEL}{A finite-width effect not explained by the frozen NTK}
	{\textcolor{muted}{After controlling the frozen operator, the next question is whether training changes the operator enough to matter.}}

	\pause

% ------------------------------------------------------------------
\begin{frame}
	\note<1->{
		The first possible explanation is geometric: maybe training helps because the
		evolving kernel aligns its eigenspaces better with the Fourier modes. These
		plots rule out that simple story. At width 128, the low modes remain aligned,
		but the higher-frequency blocks lose alignment. At width 1024, the frozen
		initialization is already very well aligned, and the evolving kernel again
		moves several higher-frequency blocks away from the Fourier reference. So
		the small-width improvement is not coming from better Fourier alignment.
	}
	\slidetitle{EVOLVING KERNEL}{First check: does alignment improve?}
	{\textcolor{muted}{If evolution helped by preserving Fourier geometry, the alignment curves should rise. They do not.}}

	\vspace{1mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.49\textwidth}
			\begin{whitecard}
				\centering
				\includegraphics[width=\linewidth,height=27mm,keepaspectratio]{rms_cos_alignment_by_freq_w128.png}\par
				{\tiny $m=128$: higher-frequency alignment drops sharply.}
			\end{whitecard}
		\end{column}
		\begin{column}{0.49\textwidth}
			\begin{whitecard}
				\centering
				\includegraphics[width=\linewidth,height=27mm,keepaspectratio]{rms_cos_alignment_by_freq_w1024.png}\par
				{\tiny $m=1024$: frozen alignment starts stronger, but evolution still worsens high frequencies.}
			\end{whitecard}
		\end{column}
	\end{columns}

	\vspace{2mm}
	\begin{bluecard}
		\centering
		{\bfseries Alignment is not the gain. The moving kernel does not become more Fourier-diagonal.}
	\end{bluecard}
\end{frame}

% ------------------------------------------------------------------
\begin{frame}
	\note<1->{
		The second explanation is strength. The operator can become stronger on
		some frequency blocks even if its eigenspaces are not better aligned. This
		is what the spectral-strength plots show. At width 128, the strength in the
		constant block and the first frequency rises sharply, with a smaller gain
		for k equals 2. At width 1024, the same direction of change is still visible
		but much weaker. This tracks the loss comparison: the low-frequency boost is
		large where evolving wins and small where frozen wins. This is still a
		correlation with lower loss, not a causal proof, and the mechanism behind
		the low-frequency boost remains open.
	}
	\slidetitle{EVOLVING KERNEL}{What changes: low-frequency strength rises}
	{\textcolor{muted}{The benefit tracks operator strength on the low-frequency blocks, not better alignment.}}

	\vspace{1mm}

\begin{frame}[noframenumbering]
	\slidetitle{}{Finite-scale bounds: precise statements}
	{\textcolor{muted}{$\mathcal H_K$: span of the Fourier modes up to frequency $K$, $d=2K+1$; $\Phi$: those modes evaluated at the $n$ samples; $\|\cdot\|_{\max}$: entrywise max.}}

	\vspace{1.5mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.52\textwidth}
			\begin{yellowcard}
				{\textcolor{orange}{\bfseries Finite samples}\hfill{\tiny\textcolor{muted}{Thm.~5.5}}}\par\vspace{1mm}
				{\scriptsize Sampled kernel, Gram, and compressed operator:}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						A_{ij}=\tfrac1n T_\infty(\theta_i,\theta_j),
						\qquad
						G=\tfrac1n\Phi^\top\Phi,
						\qquad
						H=\tfrac1n\Phi^\top A\Phi
					\]
				}
				\vspace{-3.5mm}\par
				{\scriptsize With probability at least $1-\delta$:}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\begin{aligned}
							\|G-I\|_{\max}
							 & \le
							C_1\sqrt{\tfrac{\log(d/\delta)}{n}}
							 &     & \text{(orthogonality)} \\[0.6mm]
							\|H-\Lambda^{(n)}\|_{\max}
							 & \le
							C_2\sqrt{\tfrac{\log(d/\delta)}{n}}
							 &     & \text{(eigenvalues)}   \\[0.6mm]
							\|A\Phi-\Phi\Lambda^{(n)}\|_{\max}
							 & \le
							C_3\sqrt{\tfrac{\log(nd/\delta)}{n}}
							 &     & \text{(kernel action)}
						\end{aligned}
					\]
				}
				\vspace{-2.5mm}\par
				{\tiny\textcolor{muted}{$\Lambda^{(n)}$: ideal eigenvalues with an $O(1/n)$ correction; $\mathbb{E}[H]=\Lambda^{(n)}$ (Prop.~5.4).}}
			\end{yellowcard}
		\end{column}
		\begin{column}{0.46\textwidth}
			\begin{purplecard}
				{\textcolor{purple}{\bfseries Frozen finite width}\hfill{\tiny\textcolor{muted}{Thm.~5.6}}}\par\vspace{1mm}
				{\scriptsize Compress the width-$m$ tangent operator at initialization to $\mathcal H_K$:}\par\vspace{-1.5mm}
				{\scriptsize
				\[
					B_m^{(K)}=P_K T_0^{(m)} P_K,
					\qquad
					\Lambda_K=P_K T_\infty P_K
				\]
				}
				\vspace{-3.5mm}\par
				{\scriptsize Unbiased at every width, and concentrating:}\par\vspace{-1.5mm}
				{\scriptsize
				\[
					\mathbb{E}\,B_m^{(K)}=\Lambda_K
				\]
				}
				\vspace{-4mm}\par
				{\scriptsize
				\[
					\|B_m^{(K)}-\Lambda_K\|_{\max}
					\le
					C_4\sqrt{\tfrac{\log(d/\delta)}{m}}
				\]
				}
				\vspace{-2.5mm}\par
				{\tiny\textcolor{muted}{with probability at least $1-\delta$; sub-exponential regime omitted.}}
			\end{purplecard}
		\end{column}
	\end{columns}
\end{frame}
