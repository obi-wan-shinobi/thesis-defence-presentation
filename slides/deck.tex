\begin{frame}
	\note<1->{
		A neural network is just a rule that turns an input into an output,
		which is what we mean by a function. We are given example input output
		pairs and we want a function that agrees with them and, more
		importantly, gives sensible answers for inputs we have not seen, which
		is what generalize means. The way we get there is to adjust the
		function until its outputs on the examples are close to the true
		outputs, and the squared error written here just measures how far off
		it is. But we cannot try arbitrary functions one by one, so instead we
		fix a family of functions described by a set of adjustable numbers, the
		parameters, and learning means tuning those numbers. Keep the word
		unknowns in mind: the next motivation slide counts parameters against
		data points exactly like unknowns against equations. The next slide
		looks at what such a function is actually built from.
	}
	\vspace{0.5em}
	\slidetitle{INTRODUCTION}{Supervised Learning: Fitting data to a function}

	\vfill
	\begin{columns}[c,onlytextwidth]
		\begin{column}{0.52\textwidth}
			\setlength{\parskip}{2.2mm}\small

			\visible<2->{{\color{blue}\bfseries Data:}\ \ $n$ observations $(x_i, \targetf(x_i))$, examples of an unknown target function $\targetf$.\par}

			\visible<3->{{\color{green}\bfseries Model:}\ \ a learned prediction function $\modelf(x)$.\par}

			\visible<4->{{\color{blue}\bfseries Aim:}\ \ predict the target output $\targetf(x)$ for a new, unseen input $x$.\par}

			\visible<5->{{\color{orange}\bfseries How:}\ \ choose $\modelf$ so its predictions are close to the target function on the observed data, i.e.\ minimise
				$\mathcal{L}(f) = \displaystyle\frac{1}{n}\sum_{i=1}^{n}\big(\underbrace{\modelf(x_i)-\targetf(x_i)}_{:=\,r_i}\big)^2$.\par}

			\visible<6->{{\color{green}\bfseries In practice:}\ \ we cannot
				search over all possible functions, so we fix a parameterized
				family ${\color{tudcyan}f_\theta}(x)$ and learn by adjusting the
				parameters $\theta$. The parameters are the unknowns the data must
				pin down.\par}
		\end{column}
		\begin{column}{0.40\textwidth}
			\centering
			\input{fit_intuition.tex}
		\end{column}
	\end{columns}

\begin{frame}
	\note<1->{
		Spectral bias is the tendency of neural networks trained with gradient descent to learn low-frequency structure before high-frequency detail.

		In other words, the network first captures the smooth, global shape of the target, and only later fits the more oscillatory parts.

		That is what these examples are meant to show. Even though the architectures are different, the learning process has the same qualitative pattern: low-frequency modes appear early, high-frequency modes are delayed.

		My thesis asks whether we can explain this from the training dynamics.

		The main idea is to reformulate spectral bias as an operator eigenvalue problem. If an operator governs the residual dynamics, then its eigenvalues determine which frequencies are learned quickly and which ones are learned slowly.

		So the three guiding questions are: what controls mode-wise learning rates, does the explanation survive finite data, and does it survive finite width?
	}
	\vspace{0.5em}
	\slidetitle{THESIS}{Why does gradient descent learn simple structure first?}
	{\small\textcolor{muted}{This pattern has a name: the frequency principle, also called spectral bias (\href{https://arxiv.org/abs/1901.06523}{Xu et al., 2019}).}}

\begin{frame}
	\note<1->{
		Picture the error as a landscape: high where the network is wrong, low
		where it fits. Training rolls downhill, taking the steepest way down, which
		is why it is called gradient descent. Notice the steps shrink as it nears
		the bottom: the closer the error gets to zero, the smaller the correction,
		because the slope itself is proportional to how much error is left. Then we
		look at the same bowl from straight above. The rings are contours, lines of
		equal height, so closely spaced rings mean steep and widely spaced rings
		mean shallow. This bowl has a steep direction and a shallow one, and that is
		the distinction the next slide builds on.
	}
	\vspace{0.5em}
	\slidetitle{BACKGROUND}{The error is a landscape}
	{\textcolor{muted}{Seen from above, the contour rings are the bowl's height; training rolls toward the bottom.}}

	{\raggedleft\tiny\textcolor{muted}{recall the loss: $\mathcal{L}(f) = \tfrac1n\sum_i\big(f(x_i)-f^\star(x_i)\big)^2$}\par}

% Keystone slide: "rate = eigenvalue", introduced geometrically before any
% NTK machinery. Self-contained TikZ (no external assets).
\begin{frame}
	\note<1->{
		One sentence on what training does: it makes the error small. It does this by
		walking downhill on the error, stepping in the direction the error drops
		fastest, which is the negative gradient, hence gradient descent. Now the
		question this slide answers: why do different directions get learned at
		different speeds. Picture the error landscape as a stretched bowl. In the
		bowl's own tilted coordinates the descent path mixes the two directions
		together, so you cannot read off a clean rate for either one. The fix is to
		use the bowl's own axes as coordinates. These special directions, the
		eigenvectors, are the ones the dynamics never mixes. Along a single one of
		them the error falls in proportion to how much is left, the differential
		equation here, which is the same law as a cooling cup of coffee or
		radioactive half-life, so it decays exponentially, alpha of t equals alpha of
		zero times e to the minus lambda t. The rate lambda is the eigenvalue, large
		is fast, small is slow. Everything after this works out what these directions
		and rates are for a real network on the circle.
	}
	\vspace{0.4em}
	\slidetitle{BACKGROUND}{Each direction has its own rate}
	{\textcolor{muted}{Training makes the error small by walking downhill, along the steepest drop.}}\par
	{\raggedleft\tiny\textcolor{muted}{recall the loss: $\mathcal{L}(f) = \tfrac1n\sum_i\big(f(x_i)-f^\star(x_i)\big)^2$}\par}

	\vspace{1mm}

\begin{frame}
	\note<1->{
		Picking up the question from the last slide. For a single direction the error
		obeyed alpha dot equals minus lambda alpha, the rate was one number. For a
		network the error is a whole function, the residual, and it still falls in
		proportion to how much is left, but the proportion is no longer a number. It
		is an operator acting on the whole function, and that operator is the neural
		tangent kernel. The residual obeys r dot equals minus T r. This holds for any
		differentiable model under gradient flow, which is why I am not writing the
		network down yet. If T were a fixed operator, diagonalizing it would split
		this back into one copy of the scalar law per eigenfunction, alpha k dot
		equals minus lambda k alpha k. So the eigenfunctions are the directions and
		the eigenvalues are the rates, and the question from the last slide becomes:
		what is the spectrum of T.
	}

	{\textcolor{muted}{The same law as before, with the single rate replaced by an operator.}}

% Message: convolution on the circle means Fourier modes diagonalize the
% dynamics; eigenvalues give learning rates.
\begin{frame}
	\note<1->{
		\begin{itemize}
			\item Infinite width and continuum data.
			\item Uniform circle makes \(T\) a convolution operator.
			\item Fourier modes diagonalize convolution.
			\item Each mode decays independently at rate \(\lambda_k\).
			\item Formula shows \(\lambda_k\sim k^{-2}\): high frequencies are slow.
		\end{itemize}
	}
	\vspace{0.2em}
	\slidetitle{REFERENCE MODEL}{The ideal picture: a convolution operator on $S^1$}
	{\textcolor{muted}{At infinite width and with continuum data, the NTK becomes fixed and rotation-invariant.}}

	{\raggedleft\tiny\textcolor{muted}{recall: fixed \(T\) gives \(\dot\alpha_k=-\lambda_k\alpha_k\)}\par}

	\vspace{0.5mm}
	\begin{whitecard}
		{\scriptsize
			With uniform measure \(\mu(d\psi)=d\psi/(2\pi)\), the fixed operator acts by
		}\par\vspace{-0.5mm}
		{\scriptsize
			\[
				(T r)(\varphi)=
				\int_{0}^{2\pi}\Theta(\varphi-\psi)\,r(\psi)\,\frac{d\psi}{2\pi}.
			\]
		}
		\vspace{-1mm}
		{\scriptsize
			Because this is a convolution on the circle, the Fourier modes are eigenfunctions:
		}\par
		{\scriptsize
		\[
			T\phi_k = \lambda_k \phi_k,
			\qquad
			\alpha_k(t)=e^{-\lambda_k t}\alpha_k(0).
		\]
		}
	\end{whitecard}

						\lambda_k =
						\left\{

							\frac14+\frac{3}{\pi^2},

\begin{frame}
	\note<1->{
		\begin{itemize}

			\item Detailed Gram and action bounds are in backup.

	\slidetitle{NON-ASYMPTOTIC CONTROL}{Main results: the spectral picture survives finite scale}
	% {\textcolor{muted}{On one fixed low-frequency subspace, finite scale turns the ideal diagonal operator into a controlled perturbation.}}

	\vspace{0.5mm}
	\begin{whitecard}
		{\centering\scriptsize
			\(\mathcal H_K=\operatorname{span}\{1,\cos\varphi,\sin\varphi,\ldots,\cos(K\varphi),\sin(K\varphi)\}\),

				{\scriptsize Let \(T_K\) be the sampled operator on \(\mathcal H_K\), using \(n\) uniform samples from \([0,2\pi)\). For every \(\varepsilon>0\),}\par\vspace{-1.5mm}

					\[
						\mathbb P\!\left(

\begin{frame}
	\note<1->{
		\begin{itemize}
			\item So far, the story has been: start from the ideal operator, then control finite-sample and frozen finite-width errors.
			\item But this still leaves out normal training.
			\item In normal training, the tangent kernel is allowed to move:
			      \[
				      T_0^{(m)} \rightsquigarrow T_t^{(m)}.
			      \]
			\item The question is whether that movement actually matters.
			\item At $m=128$ and $m=256$, it clearly does: the evolving kernel reaches lower training error than the frozen one.
			\item At $m=1024$, the reversal appears: the frozen kernel reaches the lower final loss.
			\item So kernel evolution seems to be a genuine small-width effect.

\begin{frame}
	\note<1->{
		The exact Fourier picture rests on four assumptions, and each one tells us
		what changes when it is relaxed. The uniform measure is what makes the kernel
		a convolution, so the Fourier modes are its eigenfunctions; a non-uniform
		density or Gaussian inputs change the basis to Hermite polynomials, but
		eigenvalue size still sets the rates, and the proofs would need redoing for
		unbounded support. ReLU fixes the polynomial decay of the spectrum; a smooth
		activation keeps the same eigenbasis but decays faster. Freezing the kernel
		is what gives the concentration bounds; letting it evolve is the regime we
		only study empirically. And the bounds hold on a fixed low-frequency block,
		not uniformly over all modes. The point is that the framework is robust in
		direction, but the guarantees are local to these assumptions.
	}
	\slidetitle{DISCUSSION \& LIMITATIONS}{What we assumed, and what changes if we relax it}

	\vspace{2mm}
	{\renewcommand{\arraystretch}{1.35}
		\begin{tabular}{@{}p{0.18\linewidth}p{0.33\linewidth}p{0.43\linewidth}@{}}
			\toprule
			{\scriptsize\bfseries Assumption} & {\scriptsize\bfseries What it gives us}                                                                                                                                                                                                                   & {\scriptsize\bfseries If we relax it} \\
			\midrule
			{\scriptsize\textcolor{blue}{\bfseries Uniform measure on $S^1$}}
			                                  & {\scriptsize The NTK is a convolution, so the Fourier modes are exactly its eigenfunctions.}
			                                  & {\scriptsize A non-uniform density or Gaussian inputs change the basis (e.g.\ Hermite polynomials), but eigenvalue size still sets the rates. The bounded-kernel proofs assume a compact domain, so they need rederiving for unbounded support.}                                                  \\
			{\scriptsize\textcolor{green}{\bfseries ReLU activation}}
			                                  & {\scriptsize A closed-form spectrum with polynomial decay, $\lambda_k = O(k^{-2})$.}
			                                  & {\scriptsize A smooth activation keeps the Fourier eigenbasis but decays faster, sharpening the bias. The fixed-kernel analysis carries over with the spectrum recomputed.}                                                                                                                       \\
			{\scriptsize\textcolor{orange}{\bfseries Frozen (lazy) kernel}}
			                                  & {\scriptsize Finite width is a controlled perturbation, concentrating at $O(m^{-1/2})$.}
			                                  & {\scriptsize When the kernel evolves the initial spectrum no longer governs the dynamics; at small width we observe increased low-frequency strength alongside lower training error, with the cause still open. This regime is only studied empirically.}                                         \\
			{\scriptsize\textcolor{purple}{\bfseries Fixed block $\mathcal H_K$}}

\begin{frame}
	\note<1->{
		Where this sits. The NTK turns a non-convex training problem into a linear
		one that can be characterised exactly, and our networks live between two
		regimes: lazy training, where the tangent kernel barely moves, and feature
		learning, where it moves substantially. Four points on where the work sits.
		First, it makes the NTK spectral-bias mechanism, usually argued
		asymptotically or shown empirically, explicit on the circle, where every rate
		is a computable eigenvalue. Second, the infinite-width NTK is often treated as
		a purely asymptotic object, and we instead give non-asymptotic bounds on a
		low-frequency block. Third, the fixed kernel is a useful baseline while it
		stays lazy, but it is not a full account once features are learned, and this
		work marks where that reduction stops. Fourth, the mechanism is the one
		practitioners already modify: PINNs rescale this spectrum, and Fourier
		features and SIREN reshape it. A result on the uniform circle is still far
		from a guarantee about a deployed model.
	}
	\slidetitle{DISCUSSION \& LIMITATIONS}{Where this sits, and where it connects}

	\vspace{2mm}
	{\small
		\begin{itemize}
			\setlength{\itemsep}{2.6mm}
			\item {\bfseries\textcolor{blue}{An exact, concrete case study}}
			      \begin{itemize}\tightlist\scriptsize
				      \item The NTK spectral-bias mechanism, usually argued asymptotically or shown empirically, made explicit on $S^1$, where every rate is a computable eigenvalue (\textcolor{muted}{\href{https://arxiv.org/abs/1806.07572}{Jacot et al., 2018}}; \textcolor{muted}{\href{https://arxiv.org/abs/1806.08734}{Rahaman et al., 2019}}).
			      \end{itemize}

			\item {\bfseries\textcolor{green}{Finite scale, not only the limit}}
			      \begin{itemize}\tightlist\scriptsize
				      \item The infinite-width NTK is often treated as a purely asymptotic object; we add non-asymptotic bounds on a low-frequency block, alongside work probing finite-width corrections and the kernel picture's limits (\textcolor{muted}{\href{https://arxiv.org/abs/1909.05989}{Hanin \& Nica, 2019}}; \textcolor{muted}{\href{https://arxiv.org/abs/2206.10012}{Vyas et al., 2022}}).
			      \end{itemize}

			\item {\bfseries\textcolor{orange}{A baseline, not the whole story}}
			      \begin{itemize}\tightlist\scriptsize
				      \item The fixed kernel predicts the rates while it stays lazy, but is not a full account once features are learned; this work marks where that reduction stops (\textcolor{muted}{\href{https://arxiv.org/abs/1812.07956}{Chizat et al., 2019}}).
			      \end{itemize}

			\item {\bfseries\textcolor{purple}{Connects to practice}}
			      \begin{itemize}\tightlist\scriptsize
				      \item The same spectrum PINNs rescale to fix high-frequency failure (\textcolor{muted}{\href{https://arxiv.org/abs/2007.14527}{Wang et al., 2022}}), and that Fourier features and SIREN reshape for coordinate networks (\textcolor{muted}{\href{https://arxiv.org/abs/2006.10739}{Tancik et al., 2020}}; \textcolor{muted}{\href{https://arxiv.org/abs/2006.09661}{Sitzmann et al., 2020}}).
			      \end{itemize}
		\end{itemize}
	}

	\vspace{1.5mm}
	{\scriptsize\textcolor{muted}{Still, a result on the uniform circle is far from a guarantee about a deployed model.}}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{NTK: from parameter updates to an operator on functions}
	{\textcolor{muted}{Gradient flow on the weights induces a linear flow on the residual, governed by an operator built from the network's own gradients.}}

	\vspace{1.5mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.5\textwidth}
			\begin{whitecard}[height=44mm]
				{\scriptsize\bfseries Setup}\par\vspace{1mm}
				{\scriptsize Least-squares loss on $L^2(\mu)$, with residual $r_t=f_t-y$:}\par\vspace{-1.5mm}
				{\scriptsize
				\[
					\mathcal L(\theta)=\tfrac12\|f_m(\cdot;\theta)-y\|_{L^2(\mu)}^2 .
				\]
				}
				\vspace{-3mm}\par
				{\scriptsize The empirical NTK is the gradient inner product}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\Theta_t^{(m)}(\varphi,\psi)=\bigl\langle\nabla_\theta f_t(\varphi),\nabla_\theta f_t(\psi)\bigr\rangle,
					\]
				}
				\vspace{-3mm}\par
				{\scriptsize with operator $\;(T_t^{(m)}f)(\varphi)=\int \Theta_t^{(m)}(\varphi,\psi)f(\psi)\,d\mu(\psi)$.}
			\end{whitecard}
		\end{column}
		\begin{column}{0.5\textwidth}
			\begin{bluecard}[height=44mm]
				{\scriptsize\bfseries Residual flow}\par\vspace{1mm}
				{\scriptsize Gradient flow on $\theta$ and the chain rule give a linear flow on the residual:}\par\vspace{-1mm}
				{\scriptsize
				\[
					\partial_t r_t=-T_t^{(m)}r_t,
					\qquad
					\tfrac{d}{dt}\tfrac12\|r_t\|^2=-\langle r_t,T_t^{(m)}r_t\rangle .
				\]
				}
				\vspace{-2mm}\par
				{\scriptsize\bfseries Two regimes inside one equation:}
				\begin{itemize}\tightlist\scriptsize
					\item \textcolor{blue}{Frozen}: replace $T_t^{(m)}$ by $T_0^{(m)}$ (kernel regression on the initial features).
					\item \textcolor{orange}{Evolving}: keep the full time dependence of $T_t^{(m)}$.
				\end{itemize}
				\vspace{0.5mm}
				{\tiny\textcolor{muted}{As $m\to\infty$, $T_0^{(m)}\to T$, the deterministic continuum operator.}}
			\end{bluecard}
		\end{column}
	\end{columns}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{Finite-scale bounds: precise statements}
	{\textcolor{muted}{$\mathcal H_K$: span of the Fourier modes up to frequency $K$, $d=2K+1$; $\Phi$: those modes evaluated at the $n$ samples; $\|\cdot\|_{\max}$: entrywise max.}}
	{\tiny\textcolor{muted}{Main-slide notation: \(T_K^{(n)}\) corresponds to \(H\), and \(T_K^{(m)}\) corresponds to \(B_m^{(K)}\).}}

	\vspace{1mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.52\textwidth}
			\begin{yellowcard}
				{\textcolor{orange}{\bfseries Finite samples}\hfill{\tiny\textcolor{muted}{Thm.~5.5}}}\par\vspace{1mm}
				{\scriptsize Sampled kernel, Gram, and compressed operator:}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						A_{ij}=\tfrac1n T(\theta_i,\theta_j),
						\qquad
						G=\tfrac1n\Phi^\top\Phi,
						\qquad
						H=\tfrac1n\Phi^\top A\Phi
					\]
				}
				\vspace{-3.5mm}\par
				{\scriptsize With probability at least $1-\delta$:}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\begin{aligned}
							\|G-I\|_{\max}
							 & \le
							C_1\sqrt{\tfrac{\log(d/\delta)}{n}}
							 &     & \text{(orthogonality)} \\[0.6mm]
							\|H-\Lambda^{(n)}\|_{\max}
							 & \le
							C_2\sqrt{\tfrac{\log(d/\delta)}{n}}
							 &     & \text{(eigenvalues)}   \\[0.6mm]
							\|A\Phi-\Phi\Lambda^{(n)}\|_{\max}
							 & \le
							C_3\sqrt{\tfrac{\log(nd/\delta)}{n}}
							 &     & \text{(kernel action)}
						\end{aligned}
					\]
				}
				\vspace{-2.5mm}\par
				{\tiny\textcolor{muted}{$\Lambda^{(n)}$: ideal eigenvalues with an $O(1/n)$ correction; $\mathbb{E}[H]=\Lambda^{(n)}$ (Prop.~5.4).}}
			\end{yellowcard}
		\end{column}
		\begin{column}{0.46\textwidth}
			\begin{purplecard}
				{\textcolor{purple}{\bfseries Frozen finite width}\hfill{\tiny\textcolor{muted}{Thm.~5.6}}}\par\vspace{1mm}
				{\scriptsize Compress the width-$m$ tangent operator at initialization to $\mathcal H_K$:}\par\vspace{-1.5mm}
				{\scriptsize
				\[
					B_m^{(K)}=P_K T_0^{(m)} P_K,
					\qquad
					\Lambda_K=P_K T P_K
				\]
				}
				\vspace{-3.5mm}\par
				{\scriptsize Unbiased at every width, and concentrating:}\par\vspace{-1.5mm}
				{\scriptsize
				\[
					\mathbb{E}\,B_m^{(K)}=\Lambda_K
				\]
				}
				\vspace{-4mm}\par
				{\scriptsize
				\[
					\|B_m^{(K)}-\Lambda_K\|_{\max}
					\le
					C_4\sqrt{\tfrac{\log(d/\delta)}{m}}
				\]
				}
				\vspace{-2.5mm}\par
				{\tiny\textcolor{muted}{with probability at least $1-\delta$; sub-exponential regime omitted.}}
			\end{purplecard}
		\end{column}
	\end{columns}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{Computing the eigenvalues $\lambda_k$}
	{\textcolor{muted}{The eigenvalues are the Fourier coefficients of the convolution kernel $\Theta(\delta)$.}}

	\vspace{1.5mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.52\textwidth}
			\begin{whitecard}[height=46mm]
				{\scriptsize\bfseries From gradients to a closed-form kernel}\par\vspace{1mm}
				{\scriptsize At init ($a_i,w_i\sim\mathcal N(0,I)$, $b_i=0$), the width-$m$ NTK concentrates on}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\Theta(x,y)=K_0+(x^\top y+1)K_1,
					\]
				}
				\vspace{-3mm}\par
				{\scriptsize with the ReLU expectations (angle $\delta$, $\cos\delta=x^\top y$)}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						K_1=\tfrac{\pi-\delta}{2\pi},
						\quad
						K_0=\tfrac{1}{2\pi}\bigl(\sin\delta+(\pi-\delta)\cos\delta\bigr),
					\]
				}
				\vspace{-3mm}\par
				{\scriptsize so that}\par\vspace{-2mm}
				{\scriptsize
					\[
						\Theta(\delta)=\tfrac{1}{2\pi}\bigl(\sin\delta+2(\pi-\delta)\cos\delta+(\pi-\delta)\bigr).
					\]
				}
			\end{whitecard}
		\end{column}
		\begin{column}{0.46\textwidth}
			\begin{bluecard}[height=46mm]
				{\scriptsize\bfseries Convolution $\Rightarrow$ Fourier diagonal}\par\vspace{1mm}
				{\scriptsize $\Theta$ depends only on $\delta=\varphi-\psi$, so $T$ is a convolution and}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\lambda_k=\frac{1}{\pi}\int_0^\pi \Theta(\delta)\cos(k\delta)\,d\delta .
					\]
				}
				\vspace{-2.5mm}\par
				{\scriptsize The parity integral $\int_0^\pi(\pi-\delta)\cos(m\delta)\,d\delta=\tfrac{1-(-1)^m}{m^2}$ splits even and odd $k$:}\par\vspace{0.5mm}
				{\scriptsize
					\[
						\lambda_0=\tfrac14+\tfrac{3}{\pi^2},\quad
						\lambda_1=\tfrac14+\tfrac{1}{\pi^2},
					\]
					\[
						\lambda_k=\begin{cases}\tfrac{k^2+3}{\pi^2(k^2-1)^2}, & k\ge2\text{ even},\\[1mm]\tfrac{1}{\pi^2 k^2}, & k\ge3\text{ odd}.\end{cases}
					\]
				}
			\end{bluecard}
		\end{column}
	\end{columns}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{The $k=2$ alignment anomaly}
	{\textcolor{muted}{$\lambda_2$ follows the generic even-$k$ formula normally. The anomaly is in the geometry: at finite width, $k=2$ is unusually well aligned with its Fourier subspace.}}

	\vspace{2mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.5\textwidth}
			\begin{whitecard}[height=40mm]
				{\scriptsize\bfseries Observation}\par\vspace{1mm}
				\begin{itemize}\tightlist\scriptsize
					\item Projector error grows with frequency, as expected, with one exception: $k=2$ has the smallest error among the displayed frequencies.
					\item It is also the best aligned, sitting above its neighbours rather than on the decreasing trend.
				\end{itemize}
			\end{whitecard}
		\end{column}
		\begin{column}{0.5\textwidth}
			\begin{bluecard}[height=40mm]
				{\scriptsize\bfseries A tentative explanation}\par\vspace{1mm}
				\begin{itemize}\tightlist\scriptsize
					\item $k=0$ gets a direct eigenvalue from the bias; $k=1$ is tied to the coordinate embedding and is the only odd mode in the no-bias kernel.
					\item The finite-width perturbation may therefore act differently on $k=0,1$ than on higher blocks, leaving $k=2$ relatively favoured.
				\end{itemize}
				\vspace{0.5mm}
				{\tiny\textcolor{muted}{This is an empirical observation, not a theoretical claim; the mechanism is not investigated further.}}
			\end{bluecard}
		\end{column}
	\end{columns}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{Eigenvalue ordering: where it holds, and what it depends on}
	{\textcolor{muted}{Because the domain and measure are rotation-symmetric, the eigenvalue ordering is also a frequency ordering. The trainable bias is what keeps it strict.}}

	\vspace{1.5mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.46\textwidth}
			\begin{whitecard}[height=42mm]
				{\scriptsize\bfseries The spectrum is strictly decreasing}\par\vspace{1mm}
				{\scriptsize
					\begin{tabular}{@{}ll@{}}
						$\lambda_0\approx0.554$  & $\lambda_1\approx0.351$  \\
						$\lambda_2\approx0.079$  & $\lambda_3\approx0.011$  \\
						$\lambda_4\approx0.0086$ & $\lambda_5\approx0.0041$ \\
					\end{tabular}
				}\par\vspace{1.5mm}
				{\scriptsize Two interleaved subsequences (even and odd $k$), both $O(k^{-2})$, with $\lambda_k>\lambda_{k+1}$ throughout.}
			\end{whitecard}
		\end{column}
		\begin{column}{0.52\textwidth}
			\begin{orangecard}[height=42mm]
				{\scriptsize\bfseries What the ordering depends on}\par\vspace{1mm}
				\begin{itemize}\tightlist\scriptsize
					\item The gap between $k=0,1$ and the rest comes from the constant and the coordinate embedding.
					\item The odd modes $k\ge3$ are nonzero \emph{only} because of the trainable hidden bias. Without it, $\lambda^{(\mathrm{nb})}_k=0$ for odd $k\ge3$, so those modes are null and never learned by the fixed kernel.
					\item Even $k\ge2$ are unchanged by the bias.
				\end{itemize}
				\vspace{0.5mm}
				{\tiny\textcolor{muted}{Consistent with bias-free two-layer ReLU models not expressing odd harmonics beyond $k=1$.}}
			\end{orangecard}
		\end{column}
	\end{columns}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{Mean-field viewpoint: a complementary large-width limit}
	{\textcolor{muted}{The NTK is one way to take width to infinity. The mean-field limit is another, and it is what makes the evolving-kernel regime natural.}}

	\vspace{2mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.5\textwidth}
			\begin{bluecard}[height=42mm]
				{\scriptsize\textcolor{blue}{\bfseries NTK / lazy limit}}\par\vspace{1mm}
				\begin{itemize}\tightlist\scriptsize
					\item Track a \emph{fixed} tangent operator at initialization.
					\item On $S^1$ it is diagonal in the Fourier basis, so learning is read off eigenvalues and eigenspaces.
					\item Features barely move; this is the regime our bounds control.
				\end{itemize}
			\end{bluecard}
		\end{column}
		\begin{column}{0.5\textwidth}
			\begin{orangecard}[height=42mm]
				{\scriptsize\textcolor{orange}{\bfseries Mean-field limit}}\par\vspace{1mm}
				{\scriptsize With scaling $f_\theta=\tfrac1m\sum_\alpha v_\alpha\varphi(w_\alpha^\top x)$, the output depends on the neurons only through their empirical measure}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\mu_m=\tfrac1m\textstyle\sum_\alpha \delta_{\theta_\alpha}\;\longrightarrow\;\mu_t .
					\]
				}
				\vspace{-2mm}\par
				\begin{itemize}\tightlist\scriptsize
					\item Training is a flow of the \emph{distribution} of neurons, not a fixed kernel.
					\item This is the language for the feature-learning side where the kernel evolves.
				\end{itemize}
			\end{orangecard}
		\end{column}
	\end{columns}
\end{frame}
