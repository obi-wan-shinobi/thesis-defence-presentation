\begin{frame}
	\note<1->{
		Supervised learning is about learning from examples. We have inputs
		and targets from an unknown function, and our goal is to learn a
		prediction function that is close to that unknown function. Since
		we cannot search over all possible functions, we choose a
		parameterized family \(f_\theta\), and training means adjusting the
		parameters \(\theta\).
	}
	\vspace{0.5em}
	\slidetitle{INTRODUCTION}{Supervised Learning: Fitting a function to data}

	\vfill
	\begin{columns}[c,onlytextwidth]
		\begin{column}{0.52\textwidth}
			\setlength{\parskip}{2.2mm}\small

			\visible<2->{{\color{blue}\bfseries Data:}\ \ $n$ observations $(x_i, \targetf(x_i))$, examples of an unknown target function $\targetf$.\par}

			\visible<3->{{\color{green}\bfseries Model:}\ \ a learned prediction function $\modelf(x)$.\par}

			\visible<4->{{\color{blue}\bfseries Aim:}\ \ predict the target output $\targetf(x)$ for a new, unseen input $x$.\par}

			\visible<5->{{\color{orange}\bfseries How:}\ \ choose $\modelf$ so its predictions are close to the target function on the observed data, i.e.\ minimise
				$\mathcal{L}(f) = \displaystyle\frac{1}{n}\sum_{i=1}^{n}\big(\underbrace{\modelf(x_i)-\targetf(x_i)}_{:=\,r_i}\big)^2$.\par}

			\visible<6->{{\color{green}\bfseries In practice:}\ \ we cannot
				search over all possible functions, so we fix a parameterized
				family ${\color{tudcyan}f_\theta}(x)$ and learn by adjusting the
				parameters $\theta$. The parameters are the unknowns the data must
				pin down.\par}
		\end{column}
		\begin{column}{0.40\textwidth}
			\centering
			\input{fit_intuition.tex}
		\end{column}
	\end{columns}
	\vfill
\end{frame}

\begin{frame}
	\note<1->{
		We know from basic linear algebra: if we have as many
		independent equations as unknowns, we usually get one solution. But
		if we have more unknowns than equations, many solutions can fit the
		same constraints.

		In neural networks, each training example acts like a constraint on
		the parameters. If we have many more parameters than examples, we
		can fit the training data in many different ways. This is
		overparameterization.

		The surprising part is that these networks often still work well on
		unseen data. For example, on CIFAR-10, a very large Wide ResNet has
		millions of parameters but still achieves low test error. So
		fitting the training set alone cannot be the whole explanation.

		This is why the learning process itself matters. Empirically,
		researchers have observed that networks often learn simple
		structure before complex detail.
	}

% Keystone slide: "rate = eigenvalue", introduced geometrically before any
% NTK machinery. Self-contained TikZ (no external assets).
\begin{frame}
	\note<1->{
		\begin{itemize}
			\item Gradient descent reduces the error by moving downhill. In ordinary coordinates, the motion can look coupled: changing one coordinate also affects the other.
			\item But if we rotate to the bowl's own axes, the motion separates into independent directions.
			\item Along each direction, the error decays in proportion to how much error is still left there.
			\item This gives exponential decay. The special directions are eigenvectors, and their rates are eigenvalues.
			\item The question is: what are the corresponding directions and rates for a neural network?
		\end{itemize}
	}
	\vspace{0.4em}
	\slidetitle{BACKGROUND}{Each direction has its own rate}
	{\textcolor{muted}{Training makes the error small by walking downhill, along the steepest drop.}}\par
	{\raggedleft\tiny\textcolor{muted}{recall the loss: $\mathcal{L}(f) = \tfrac1n\sum_i\big(f(x_i)-f^\star(x_i)\big)^2$}\par}

	\vspace{1mm}
	% ---------- ROW 1: the bowl, coupled then rotated to its own axes ----------
	\begin{columns}[c,onlytextwidth]
		\begin{column}{0.45\textwidth}
			\centering
			\visible<1->{
				\begin{tikzpicture}[scale=0.50]
					% Handed x, y axes (kept); the bowl is tilted RELATIVE to them.
					% Matches the lead-in "error is a landscape" frozen frame.
					\draw[line] (-2.5,0)--(2.5,0);
					\draw[line] (0,-1.7)--(0,1.7);
					\node[muted,font=\tiny] at (2.66,0.0) {$x$};

% closing question in principle; stays model-agnostic (no f_m yet, that is SETUP).
\begin{frame}
	\note<1->{
		\begin{itemize}
			\item If our error only has 1 direction then the rate is usually given by a single number
			\item But our error is a whole function, so we are no longer
			      tracking a single scalar error; we are tracking the evolution of
			      the entire residual function, so that single scalar is replaced by
			      an operator T, which is the Neural Tangent Kernel operator.
			\item This equation is not as simple to solve as the example we saw
			      earlier because T changes over time, i.e. the rate changes over
			      time. If the operator were constant, then we could diagonalize it and split
			      it back into one copy of scalar law per direction, where each
			      direction was an eigenfunction and rates the eigenvalues. Together,
			      this is called the spectrum of an operator.
			\item So to understand training, we need to understand the spectrum of this operator...
		\end{itemize}
	}

% Reference model: the ideal infinite-width / continuum-data operator.
% Message: convolution on the circle means Fourier modes diagonalize the
% dynamics; eigenvalues give learning rates.
\begin{frame}
	\note<1->{
		\begin{itemize}
			\item And infinite width and the continuum of input data, the
			      operator, under the uniform measure, becomes an integral operator
			      of this form. This operation is called a convolution where Theta is
			      the kernel of convolution, the neural tangent kernel, the object which
			      becomes fixed and rotation invariant under the infinite width
			      limit.
			\item The eigenfunctions of a convolution operator are the Fourier modes so error along each of these modes decays at a rate dictated by their corresponding eigenvalues.
			\item An explicit computation shows us that low frequency modes have larger eigenvalues so they decay faster than higher frequency modes that have smaller eigenvalues.
			\item This gives an exact explanation for why coarse structure is learnt first by a neural network.
		\end{itemize}
	}
	\vspace{0.2em}
	\slidetitle{REFERENCE MODEL}{The ideal picture: a convolution operator on $S^1$}
	{\textcolor{muted}{At infinite width and with continuum data, the NTK becomes fixed and rotation-invariant.}}

	{\raggedleft\tiny\textcolor{muted}{recall: fixed \(T\) gives \(\dot\alpha_k=-\lambda_k\alpha_k\)}\par}

	\vspace{0.5mm}
	\begin{whitecard}[height=22mm]
		{\scriptsize
			\visible<1->With uniform measure \(\mu(d\psi)=d\psi/(2\pi)\), the fixed operator acts by
		}\hfill
		\visible<3->{\tiny\textcolor{muted}{%
				\(\displaystyle
				\Theta(\varphi,\psi)=
				\left\langle
				\nabla_\theta f(x(\varphi)),
				\nabla_\theta f(x(\psi))
				\right\rangle
				\)
			}}\par\vspace{-0.5mm}
		\visible<2->{\scriptsize
			\[
				(T r)(\varphi)=
				\int_{0}^{2\pi}\Theta(\varphi-\psi)\,r(\psi)\,\frac{d\psi}{2\pi}.
			\]
		}
		\vspace{-1mm}
		\visible<4->{\scriptsize
			Because this is a convolution on the circle, the Fourier modes are eigenfunctions:
		}\par
		\visible<5->{\scriptsize
		\[
			T\phi_k = \lambda_k \phi_k,
			\qquad
			\alpha_k(t)=e^{-\lambda_k t}\alpha_k(0).
		\]
		}

	\note<1->{
		\begin{itemize}
			\item That brings us to our main results. We answer this question by looking on
			      a subspace $H_K$, spanned by the Fourier modes upto a frequency K.
			      If $\Lambda_K$ is the ideal diagonal matrix consisting of the
			      eigenvalues corresponding to each frequency. Let $T_K$ be the
			      operator restricted to this subspace $H_K$.
			\item For n points sampled uniformly on the unit circle, we prove that with
			      high probability, the deviation between $T_K$ and $\Lambda_K$ is
			      controlled and of order 1/sqrt(n), in the number of samples.
			\item Similarly, if our network has a finite width of m neurons, then we prove that with high probability, the deviation between $T_K$ and $\Lambda_K$ is similarly controlled.
			\item Crucially, in both cases, the probability of a large deviation occurring drops exponentially with the number of samples or the number of neurons.
			\item What this gives us is confidence that our infinite-limit spectral
			      analysis remains fully valid and predictive in these practical,
			      finite settings.

\begin{frame}
	\note<1->{
		To summarize, the three questions from the start have the following
		answers.

		First, in the ideal NTK model, the learning speed of each frequency is
		set by the NTK eigenvalue. Low frequencies have larger eigenvalues, so
		they are learned faster.

		Second, this picture survives finite samples on a fixed low-frequency
		subspace, with explicit \(O(n^{-1/2})\) control.

		Third, it also survives finite width at initialization, with explicit
		\(O(m^{-1/2})\) control.

		Once the kernel evolves during training, the clean spectral picture no
		longer fully explains the dynamics, but we empirically see increased
		low-frequency strength at small width.

\begin{frame}
	\note<1->{
		Let us reflect on the assumptions behind our results.
		\begin{itemize}

			\item We relied on a clean setting: uniform distribution on the unit circle gives
			      a convolution, hence Fourier modes are exact eigenfunctions. If we change
			      the distribution, it is no longer a convolution, and we get different
			      eigenfunctions. For instance, with Gaussian measure, we would expect the eigenfunctions
			      to be Hermite polynomials, the orthogonal basis of $L^2$ functions with Gaussian measure.

			\item We used one hidden layer so we could explicitly compute the eigenvalues.
			      If we change the architecture, the kernel changes, and so
			      does the spectrum. Deeper networks may still preserve Fourier
			      modes under rotation symmetry, but the eigenvalues are
			      different and usually less explicit.

			\item With ReLU, we had polynomial decay in the eigenvalues. Smoother activations like tanh or sigmoid
			      could decay faster, possibly exponentially, making high frequencies even
			      slower relative to low frequencies.

			\item Once the kernel evolves, the initial spectrum does not fully explain
			      training. Empirically, we saw low-frequency boosts at small width.

			\item Finally, our bounds are local to the chosen frequency block. If that block
			      grows, our bounds grow too.
		\end{itemize}
	}
	\vspace{0.5em}
	\slidetitle{DISCUSSION \& LIMITATIONS}{Which assumptions carry the result?}
	{\textcolor{muted}{The exact Fourier picture is local to the clean setting; the operator viewpoint is what survives.}}

	\vspace{2mm}

	{\scriptsize
		\centering
		\textbf{Clean setting:}\quad
		uniform data on \(S^1\)
		\(\;+\;\)
		1-hidden-layer
		\(\;+\;\)
		ReLU
		\(\;+\;\)
		frozen kernel
		\(\;+\;\)
		fixed \(\mathcal H_K\)
		\[
			\Longrightarrow
			\quad
			\text{Fourier modes are exact directions, with explicit rates } \lambda_k.
		\]
	}

	\vspace{1mm}
	{\color{line}\rule{\linewidth}{0.35pt}}

	\vspace{1.5mm}
	{\scriptsize
		\begin{itemize}
			\setlength{\itemsep}{2.2mm}

			\pause
			\item \textcolor{blue}{\bfseries Change the data distribution:}
			      Fourier modes need not be the right basis anymore.
			      On a non-uniform circle, learning follows the eigenfunctions of a density-weighted operator; with Gaussian inputs, the analogue is closer to Hermite-polynomial directions.

			      \pause
			\item \textcolor{tudcyan}{\bfseries Change the architecture:}
			      deeper or different networks change the kernel and hence the spectrum.
			      Symmetry may still give Fourier-like directions, but the rates are different and less explicit.

			      \pause
			\item \textcolor{green}{\bfseries Change the activation:}
			      the operator may keep the same eigenbasis under the same symmetry, but the eigenvalues change.
			      Smoother activations usually make eigenvalues decay faster with frequency, so fine detail becomes even slower.

			      \pause
			\item \textcolor{orange}{\bfseries Let the kernel evolve:}
			      the initial spectrum is no longer a complete description.
			      In our experiments, small-width training increases low-frequency strength, but this is an empirical diagnostic, not a causal theory.

			      \pause
			\item \textcolor{purple}{\bfseries Leave the fixed block \(\mathcal H_K\):}
			      the bounds do not control all frequencies at once.
			      High frequencies are harder because their eigenvalues are smaller, closer together, and more sensitive to perturbations.
		\end{itemize}
	}

	\vspace{1mm}
	{\color{line}\rule{\linewidth}{0.35pt}}

	\vspace{1mm}
	\centering
	\pause
	{\scriptsize\bfseries Takeaway:}
	{\scriptsize the mechanism is broader than the circle, but the exact Fourier guarantees are not.}
\end{frame}

\begin{frame}
	\note<1->{
		\begin{itemize}
			\item The NTK theory gives us a mechanism to study spectral bias and we study
			      it explicitly in a clean setting.
			\item The closest, more general result in literature is by Bowman and Montufar
			      who prove a general closeness result: finite-width, finite-sample
			      training follows the ideal NTK function-space trajectory up to a
			      stopping time. This means spectral bias is not just visible on the
			      training points; it holds as a function-space effect. Compared with
			      them, this work is narrower but more explicit in separating the effects of
			      finite-sample and finite-width perturbations via concentration.
			\item The experiments with evolving kernel sit somewhere at the boundary of lazy training regime by trying to isolate the effect of feature learning.
			\item Practically, this spectral viewpoint connects to settings
			      like PINNs where different components of a solution converge at
			      very different speeds and there are methods similar to our
			      preconditioning experiments to rescale those directions for the
			      components.
			\item In many computer vision networks or networks that are coordinate based,
			      where the input is a position, finer details are harder to learn so
			      many works add Fourier features to their inputs and use sinusoidal
			      activations to change the effective spectrum so high frequency
			      details are easier to learn. So an understanding of the spectrum
			      itself can help improve these models.
			\item Still, a result on the uniform circle is far from a guarantee about a deployed model.
		\end{itemize}
	}
	\vspace{0.5em}
	\slidetitle{DISCUSSION \& LIMITATIONS}{Where this sits, and where it connects}

	\vspace{2mm}
	{\small
		\begin{itemize}
			\setlength{\itemsep}{2.7mm}

			\item {\bfseries\textcolor{blue}{A concrete version of an ideal theory}}
			      \begin{itemize}\tightlist\scriptsize
				      \item NTK theory already gives the mechanism: in the lazy limit, training is governed by a fixed operator, and its spectrum sets the learning rates. This thesis turns that into a fully explicit reference model on \(S^1\), for the shallow ReLU network actually studied here
				            (\textcolor{muted}{\href{https://arxiv.org/abs/1806.07572}{Jacot et al., 2018}};
				            \textcolor{muted}{\href{https://arxiv.org/abs/1912.01198}{Cao et al., 2020}}).
			      \end{itemize}

			      \pause
			\item {\bfseries\textcolor{green}{Less general than Bowman--Montúfar, but more inspectable}}
			      \begin{itemize}\tightlist\scriptsize
				      \item Bowman \& Montúfar compare finite networks trained on finite samples to ideal kernel dynamics in a broader setting. Here the setting is much smaller, but the perturbations are separated: sampling error and frozen-width error can be measured against known Fourier eigenvalues, mode by mode
				            (\textcolor{muted}{\href{https://arxiv.org/abs/2206.02927}{Bowman \& Mont\'ufar, 2022}}).
			      \end{itemize}

			      \pause
			\item {\bfseries\textcolor{orange}{A boundary case for the lazy-training picture}}
			      \begin{itemize}\tightlist\scriptsize
				      \item Lazy-training theory explains why the fixed kernel can be a useful approximation, but also why it is not feature learning. The evolving-kernel experiments here are a small diagnostic of that boundary: once the kernel moves, the initial spectrum no longer tells the full story
				            (\textcolor{muted}{\href{https://arxiv.org/abs/1812.07956}{Chizat et al., 2019}}).
			      \end{itemize}

			      \pause
			\item {\bfseries\textcolor{purple}{A clean model of a practical spectral problem}}
			      \begin{itemize}\tightlist\scriptsize
				      \item In PINNs, different solution components can converge at very different speeds; one explanation is imbalance in the kernel eigenvalues, and some methods try to rescale those directions
				            (\textcolor{muted}{\href{https://arxiv.org/abs/2007.14527}{Wang et al., 2022}}).
				      \item In coordinate networks, such as position \(\mapsto\) colour, shape, or audio value, fine detail is often hard to learn. Fourier features add sinusoidal coordinate encodings, and SIREN uses sinusoidal activations; both change the effective spectrum so high-frequency detail is less suppressed
				            (\textcolor{muted}{\href{https://arxiv.org/abs/2006.10739}{Tancik et al., 2020}};
				            \textcolor{muted}{\href{https://arxiv.org/abs/2006.09661}{Sitzmann et al., 2020}}).
			      \end{itemize}
		\end{itemize}
	}

	\vspace{1mm}
	{\color{line}\rule{\linewidth}{0.35pt}}

	\vspace{1mm}
	\centering
	\pause
	{\scriptsize\textcolor{muted}{Still, a result on the uniform circle is far from a guarantee about a deployed model.}}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{NTK: from parameter updates to an operator on functions}
	{\textcolor{muted}{Gradient flow on the weights induces a linear flow on the residual, governed by an operator built from the network's own gradients.}}

	\vspace{1.5mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.5\textwidth}
			\begin{whitecard}[height=44mm]
				{\scriptsize\bfseries Setup}\par\vspace{1mm}
				{\scriptsize Least-squares loss on $L^2(\mu)$, with residual $r_t=f_t-y$:}\par\vspace{-1.5mm}
				{\scriptsize
				\[
					\mathcal L(\theta)=\tfrac12\|f_m(\cdot;\theta)-y\|_{L^2(\mu)}^2 .
				\]
				}
				\vspace{-3mm}\par
				{\scriptsize The empirical NTK is the gradient inner product}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\Theta_t^{(m)}(\varphi,\psi)=\bigl\langle\nabla_\theta f_t(\varphi),\nabla_\theta f_t(\psi)\bigr\rangle,
					\]
				}
				\vspace{-3mm}\par
				{\scriptsize with operator $\;(T_t^{(m)}f)(\varphi)=\int \Theta_t^{(m)}(\varphi,\psi)f(\psi)\,d\mu(\psi)$.}
			\end{whitecard}
		\end{column}
		\begin{column}{0.5\textwidth}
			\begin{bluecard}[height=44mm]
				{\scriptsize\bfseries Residual flow}\par\vspace{1mm}
				{\scriptsize Gradient flow on $\theta$ and the chain rule give a linear flow on the residual:}\par\vspace{-1mm}
				{\scriptsize
				\[
					\partial_t r_t=-T_t^{(m)}r_t,
					\qquad
					\tfrac{d}{dt}\tfrac12\|r_t\|^2=-\langle r_t,T_t^{(m)}r_t\rangle .
				\]
				}
				\vspace{-2mm}\par
				{\scriptsize\bfseries Two regimes inside one equation:}
				\begin{itemize}\tightlist\scriptsize
					\item \textcolor{blue}{Frozen}: replace $T_t^{(m)}$ by $T_0^{(m)}$ (kernel regression on the initial features).
					\item \textcolor{orange}{Evolving}: keep the full time dependence of $T_t^{(m)}$.
				\end{itemize}
				\vspace{0.5mm}
				{\tiny\textcolor{muted}{As $m\to\infty$, $T_0^{(m)}\to T$, the deterministic continuum operator.}}
			\end{bluecard}
		\end{column}
	\end{columns}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{Finite-scale bounds: precise statements}
	{\textcolor{muted}{$\mathcal H_K$: span of the Fourier modes up to frequency $K$, $d=2K+1$; $\Phi$: those modes evaluated at the $n$ samples; $\|\cdot\|_{\max}$: entrywise max.}}
	{\tiny\textcolor{muted}{Main-slide notation: \(T_K^{(n)}\) corresponds to \(H\), and \(T_K^{(m)}\) corresponds to \(B_m^{(K)}\).}}

	\vspace{1mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.52\textwidth}
			\begin{yellowcard}
				{\textcolor{orange}{\bfseries Finite samples}\hfill{\tiny\textcolor{muted}{Thm.~5.5}}}\par\vspace{1mm}
				{\scriptsize Sampled kernel, Gram, and compressed operator:}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						A_{ij}=\tfrac1n T(\theta_i,\theta_j),
						\qquad
						G=\tfrac1n\Phi^\top\Phi,
						\qquad
						H=\tfrac1n\Phi^\top A\Phi
					\]
				}
				\vspace{-3.5mm}\par
				{\scriptsize With probability at least $1-\delta$:}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\begin{aligned}
							\|G-I\|_{\max}
							 & \le
							C_1\sqrt{\tfrac{\log(d/\delta)}{n}}
							 &     & \text{(orthogonality)} \\[0.6mm]
							\|H-\Lambda^{(n)}\|_{\max}
							 & \le
							C_2\sqrt{\tfrac{\log(d/\delta)}{n}}
							 &     & \text{(eigenvalues)}   \\[0.6mm]
							\|A\Phi-\Phi\Lambda^{(n)}\|_{\max}
							 & \le
							C_3\sqrt{\tfrac{\log(nd/\delta)}{n}}
							 &     & \text{(kernel action)}
						\end{aligned}
					\]
				}
				\vspace{-2.5mm}\par
				{\tiny\textcolor{muted}{$\Lambda^{(n)}$: ideal eigenvalues with an $O(1/n)$ correction; $\mathbb{E}[H]=\Lambda^{(n)}$ (Prop.~5.4).}}
			\end{yellowcard}
		\end{column}
		\begin{column}{0.46\textwidth}
			\begin{purplecard}
				{\textcolor{purple}{\bfseries Frozen finite width}\hfill{\tiny\textcolor{muted}{Thm.~5.6}}}\par\vspace{1mm}
				{\scriptsize Compress the width-$m$ tangent operator at initialization to $\mathcal H_K$:}\par\vspace{-1.5mm}
				{\scriptsize
				\[
					B_m^{(K)}=P_K T_0^{(m)} P_K,
					\qquad
					\Lambda_K=P_K T P_K
				\]
				}
				\vspace{-3.5mm}\par
				{\scriptsize Unbiased at every width, and concentrating:}\par\vspace{-1.5mm}
				{\scriptsize
				\[
					\mathbb{E}\,B_m^{(K)}=\Lambda_K
				\]
				}
				\vspace{-4mm}\par
				{\scriptsize
				\[
					\|B_m^{(K)}-\Lambda_K\|_{\max}
					\le
					C_4\sqrt{\tfrac{\log(d/\delta)}{m}}
				\]
				}
				\vspace{-2.5mm}\par
				{\tiny\textcolor{muted}{with probability at least $1-\delta$; sub-exponential regime omitted.}}
			\end{purplecard}
		\end{column}
	\end{columns}
\end{frame}

\begin{frame}[noframenumbering]
	\slidetitle{}{Computing the eigenvalues $\lambda_k$}
	{\textcolor{muted}{The eigenvalues are the Fourier coefficients of the convolution kernel $\Theta(\delta)$.}}

	\vspace{1.5mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.52\textwidth}
			\begin{whitecard}[height=46mm]
				{\scriptsize\bfseries From gradients to a closed-form kernel}\par\vspace{1mm}
				{\scriptsize At init ($a_i,w_i\sim\mathcal N(0,I)$, $b_i=0$), the width-$m$ NTK concentrates on}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\Theta(x,y)=K_0+(x^\top y+1)K_1,
					\]
				}
				\vspace{-3mm}\par
				{\scriptsize with the ReLU expectations (angle $\delta$, $\cos\delta=x^\top y$)}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						K_1=\tfrac{\pi-\delta}{2\pi},
						\quad
						K_0=\tfrac{1}{2\pi}\bigl(\sin\delta+(\pi-\delta)\cos\delta\bigr),
					\]
				}
				\vspace{-3mm}\par
				{\scriptsize so that}\par\vspace{-2mm}
				{\scriptsize
					\[
						\Theta(\delta)=\tfrac{1}{2\pi}\bigl(\sin\delta+2(\pi-\delta)\cos\delta+(\pi-\delta)\bigr).
					\]
				}
			\end{whitecard}
		\end{column}
		\begin{column}{0.46\textwidth}
			\begin{bluecard}[height=46mm]
				{\scriptsize\bfseries Convolution $\Rightarrow$ Fourier diagonal}\par\vspace{1mm}
				{\scriptsize $\Theta$ depends only on $\delta=\varphi-\psi$, so $T$ is a convolution and}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\lambda_k=\frac{1}{\pi}\int_0^\pi \Theta(\delta)\cos(k\delta)\,d\delta .
					\]
				}
				\vspace{-2.5mm}\par
				{\scriptsize The parity integral $\int_0^\pi(\pi-\delta)\cos(m\delta)\,d\delta=\tfrac{1-(-1)^m}{m^2}$ splits even and odd $k$:}\par\vspace{0.5mm}
				{\scriptsize
					\[
						\lambda_0=\tfrac14+\tfrac{3}{\pi^2},\quad
						\lambda_1=\tfrac14+\tfrac{1}{\pi^2},
					\]
					\[
						\lambda_k=\begin{cases}\tfrac{k^2+3}{\pi^2(k^2-1)^2}, & k\ge2\text{ even},\\[1mm]\tfrac{1}{\pi^2 k^2}, & k\ge3\text{ odd}.\end{cases}
					\]
				}
			\end{bluecard}
		\end{column}
	\end{columns}
\end{frame}

					\item The finite-width perturbation may therefore act differently on $k=0,1$ than on higher blocks, leaving $k=2$ relatively favoured.
				\end{itemize}

\begin{frame}[noframenumbering]

	{\textcolor{muted}{Because the domain and measure are rotation-symmetric, the eigenvalue ordering is also a frequency ordering. The trainable bias is what keeps it strict.}}

	\vspace{1.5mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.46\textwidth}
			\begin{whitecard}[height=42mm]

			\end{whitecard}

\begin{frame}[noframenumbering]
	\slidetitle{}{Mean-field viewpoint: a complementary large-width limit}
	{\textcolor{muted}{The NTK is one way to take width to infinity. The mean-field limit is another, and it is what makes the evolving-kernel regime natural.}}

	\vspace{2mm}
	\begin{columns}[T,onlytextwidth]
		\begin{column}{0.5\textwidth}
			\begin{bluecard}[height=42mm]
				{\scriptsize\textcolor{blue}{\bfseries NTK / lazy limit}}\par\vspace{1mm}
				\begin{itemize}\tightlist\scriptsize
					\item Track a \emph{fixed} tangent operator at initialization.
					\item On $S^1$ it is diagonal in the Fourier basis, so learning is read off eigenvalues and eigenspaces.
					\item Features barely move; this is the regime our bounds control.
				\end{itemize}
			\end{bluecard}
		\end{column}
		\begin{column}{0.5\textwidth}
			\begin{orangecard}[height=42mm]
				{\scriptsize\textcolor{orange}{\bfseries Mean-field limit}}\par\vspace{1mm}
				{\scriptsize With scaling $f_\theta=\tfrac1m\sum_\alpha v_\alpha\varphi(w_\alpha^\top x)$, the output depends on the neurons only through their empirical measure}\par\vspace{-1.5mm}
				{\scriptsize
					\[
						\mu_m=\tfrac1m\textstyle\sum_\alpha \delta_{\theta_\alpha}\;\longrightarrow\;\mu_t .
					\]
				}
				\vspace{-2mm}\par
				\begin{itemize}\tightlist\scriptsize
					\item Training is a flow of the \emph{distribution} of neurons, not a fixed kernel.
					\item This is the language for the feature-learning side where the kernel evolves.
				\end{itemize}
			\end{orangecard}
		\end{column}
	\end{columns}
\end{frame}
