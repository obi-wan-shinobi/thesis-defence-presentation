\begin{frame}
	\note<1->{
		Spectral bias is the tendency of neural networks trained with gradient descent to learn low-frequency structure before high-frequency detail.

		In other words, the network first captures the smooth, global shape of the target, and only later fits the more oscillatory parts.

		That is what these examples are meant to show. Even though the architectures are different, the learning process has the same qualitative pattern: low-frequency modes appear early, high-frequency modes are delayed.

		My thesis asks whether we can explain this from the training dynamics.

		The main idea is to reformulate spectral bias as an operator eigenvalue problem. If an operator governs the residual dynamics, then its eigenvalues determine which frequencies are learned quickly and which ones are learned slowly.

		So the three guiding questions are: what controls mode-wise learning rates, does the explanation survive finite data, and does it survive finite width?
	}
	\vspace{0.5em}
	\slidetitle{}{Why does gradient descent learn simple structure first?}

		\begin{itemize}
			\item Use $S^1$ because functions on the circle have a natural Fourier decomposition.
			\item This lets me track learning frequency by frequency.
			\item Model: one-hidden-layer ReLU MLP in NTK scaling.
			\item The Neural Tangent Kernel is the bridge from parameter updates to function evolution.
			\item Instead of tracking every weight, it tells me how gradient descent changes the network prediction.
			\item Hence, the NTK translates gradient descent on weights into an operator acting on functions. That is the bridge I use to study learning spectrally.
			\item Residual:
			      \[
				      r_t=f_t-y.

			\item Gradient flow gives:

			      \]
			\item Key question: what controls the decay of

\begin{frame}
	\note<1->{
		\begin{itemize}
			\item Start with the cleanest reference model: infinite width and continuum data.
			\item Oversimplifying slightly: the NTK measures how similarly two inputs respond to parameter changes.
			      item If two inputs have similar parameter gradients, an update for one also affects the other.
			      At finite width, the NTK is random because it depends on initialization.
			      But it is an average over neurons, so as $m\to\infty$ it converges to a deterministic limit.
			      The parameter movement becomes small enough that the limiting kernel stays fixed during training.
			      This gives a fixed operator $T_\infty$ for the residual dynamics.
			\item On $S^1$ with uniform measure, the limiting kernel only depends on angular difference:
			\item Main point: eigenvalue = learning rate.
			\item Explicit eigenvalues show $\lambda_k\sim k^{-2}$.
			\item Low frequencies decay faster; high frequencies are delayed.
			\item This is the exact reference model for the rest of the thesis.
		\end{itemize}
	}
	\slidetitle{REFERENCE MODEL}{The ideal picture: infinite-width MLP on $S^1$}
	\pause
	{\small\textcolor{muted}{With the uniform measure $\mu(d\varphi)=d\varphi/(2\pi)$, the infinite-width NTK is a fixed convolution operator.}}
	{\textcolor{muted}{At infinite width and in the continuum, spectral bias becomes an eigenvalue statement.}}

\begin{frame}
	\note<1->{
		\begin{itemize}
			\item $\Phi$ is a matrix whose columns are the Fourier modes upto K frequency,
			      and rows are those Fourier modes evaluated on the sampled points.
			\item \(A\) is the kernel matrix on the sampled points. Then G checks what the sample does to the Fourier coordinates, and H checks what the sampled kernel looks like in those coordinates.
			\item On the finite-width side, is the finite-width operator restricted to the low Fourier modes, and \(\Lambda_K\)
			      is the ideal infinite-width reference.

			\item Bounds say finite-scale objects stay close to continuum objects.
			\item Finite-sample errors scale like $n^{-1/2}$, up to logarithmic factors.
			\item Frozen finite-width error scales like $m^{-1/2}$, up to logarithmic factors.
			\item Main message: Fourier structure survives finite sampling and frozen finite width with explicit high-probability control.
		\end{itemize}
	}

\begin{frame}
	\note<1->{
		\begin{itemize}
			\item So far, the story has been: start from the ideal operator, then control finite-sample and frozen finite-width errors.
			\item But this still leaves out normal training.
			\item In normal training, the tangent kernel is allowed to move:
			      \[
				      T_0^{(m)} \rightsquigarrow T_t^{(m)}.
			      \]
			\item The question is whether that movement actually matters.
			\item At $m=128$, it clearly does: the evolving kernel reaches much lower loss than the frozen one.
			\item At $m=1024$, the advantage mostly disappears.
			\item So kernel evolution seems to be a genuine small-width effect.
			\item This is the main tension: finite width can improve learning by changing the operator, but it also breaks the clean spectral reference model.
		\end{itemize}
	}
	\slidetitle{EVOLVING KERNEL}{A finite-width effect not explained by the frozen NTK}
	{\textcolor{muted}{After controlling the frozen operator, the next question is whether training changes the operator enough to matter.}}

			\item But now $T_t^{(m)}$ is allowed to change while the network trains.
			\item So the network is not only following a fixed learning rule; the learning rule itself is changing.
			\item At small width, this change is quite visible.
			\item The kernel can become stronger on the low-frequency parts of the target.
			\item This helps explain why the evolving network can reduce the loss faster.
			\item But there is also a downside: the clean Fourier picture becomes less exact.
			\item So kernel evolution has two sides: it can help learning, but it makes the theory harder.
			\item For finite samples and frozen finite width, I can prove concentration bounds.
			\item For normal training, the harder object is:
			      \[
				      T_t^{(m)}-T_0^{(m)}.
			      \]
			\item In words: can we control how much the learning operator moves during training?
			\item Thesis takeaway: start with an exact spectral model, prove when it survives finite scale, and identify where normal finite-width training goes beyond it.
